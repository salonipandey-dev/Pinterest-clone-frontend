# 📌 Pinterest Clone

A frontend clone of Pinterest built using **HTML, CSS, and JavaScript**. This project replicates the core layout, visual aesthetic, and user interface features of Pinterest, including a responsive image grid/feed layout.

---

## Features

* **Masonry/Grid Layout:** Dynamic pin layout styled to mimic Pinterest's signature feed.
* **Responsive Design:** Adapts seamlessly across desktop, tablet, and mobile viewports.
* **Interactive UI:** Smooth transitions and hover actions on pins and navigation elements.
* **Clean Code Structure:** Modular and organized HTML, CSS, and JavaScript files.

---

## Tech Stack

* **HTML5:** Semantic markup and structure.
* **CSS3:** Styling, Flexbox/Grid layouts, and responsive design.
* **JavaScript (ES6+):** Dynamic content rendering and DOM manipulation.
